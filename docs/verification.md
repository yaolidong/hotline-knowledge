## 真实 P0 验收方式

1. 按部署说明配置真实模型、OpenSPG 专用测试项目及对应 Neo4j，导入生成的 Schema。
2. 使用 `HotlineTest` 开头的命名空间，确保是隔离的测试项目。
3. 显式启用 `HOTLINE_RUN_LIVE=1` 后运行 `python -m pytest -m live -q`。该测试会导入标记为合成的 TXT，通过实际模型抽取，并核对关键实体，再走审核、实际图写入/回读与客服查询。
4. 该测试会保留测试图数据，不执行清库；测试项目不要承载正式数据。运行前确认 `.env` 指向测试项目。通过测试后还需在真实服务的 Web 工作台确认节点、关系、原文与问答一致。

本次以上步骤及真实浏览器确认均已完成。客服展示优化后，又运行了 `scripts/browser_live.py` 和九类实际图查询回归；最新查询报告在 `data/validation/20261103T152438Z-graph/`。

未启用时 live 测试明确 skip，不会启用 Mock 代替。人工抽取质量回归可使用 `scripts/evaluate_extraction.py` 对实际输出与**完整人工标注**计算指标；`examples/expected_facts.json` 只是最小检查项，不能当作全量质量基准。
