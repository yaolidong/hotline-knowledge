# 自然语言检索未命中修复与输入方式

## 复现原因

原问句：“辽宁省食品餐饮许可证申请，申请人需要满足哪些条件”。已核实公开指南版本 `70e2524c3b4f4abdbeb589939ad52593` 为 PUBLISHED，包含对应条件关系。失败不是未发布引起：旧图事项检索要求原问句包含完整事项名“食品经营许可证”，且地区仅支持精确值“辽宁省阜新市太平区”。原问句中的“食品餐饮许可证”和“辽宁省”均未正确匹配。QA 原文回退还可能因其他地区的通用“申请条件”命中而要求澄清，却没有展示真正相关的指南。

## 已实现

- `retrieval.py` 识别已发布来源中的行政层级及问句常见地区表达；识别到库中不存在的地区时限制范围，防止回退到其他省份。
- 优先调用原精确事项检索；未命中时读取真实图中的已发布候选，结合名称、已有别名与真实文档标题的词面重合排序。最多读取 500 个事项节点，超限明确要求缩小范围；最多展示 10 个候选，不把截断结果当作完整清单。
- 近似名称与上下级地区匹配只产生待确认候选，不自动合并实体或将区级要求上推到全省。原问句现在返回食品经营许可餐饮指南及实际适用地区，用户一键确认后重新检索原问题。
- 查询结果新增 `scope`（本轮解析范围）、`retrieval.method`（匹配状态），`services` 增加真实标题 `title`。原文召回与模型回答使用同一个解析范围；待确认时不调用模型生成政策答案。
- 候选在证据侧栏标注为“尚未作为本轮政策答案”，支持先阅读原件。点击候选按其地区、事项重新发送原问题。
- 资料发布白名单、证据校验、时效判断和权限保持原机制，没有修改图数据或新增数据库结构。

## 输入方式评估

地区、日期、事项均不是必填项，页面已明确标注“查询范围（可选）”。建议客服直接输入问题，这三项保留为人工校正入口：

| 项目 | 建议默认行为 | 需要补充时 |
|---|---|---|
| 地区 | 识别问句、继承同事项的已确认范围 | 跨地区、多候选、区级资料与省级问题范围不一致 |
| 事项 | 根据问句召回图中实际存在的事项 | 名称相近且业务不同、候选不唯一 |
| 日期 | 默认今天 | 历史问题或明确指定查询日期 |

无需在每轮提问前填写三项。建议后续将筛选控件默认折叠、展示解析后的范围摘要。模型可辅助识别意图和选择候选，但范围校验、发布状态与证据过滤由后端控制，不能直接执行模型生成的任意 Cypher。

当前地区识别与候选排序是有限规则/词面召回，**并非完整语义检索或地理实体识别**。日期仍来自显式日期控件或当天，尚未实现从“2023 年当时怎么办”等问句可靠解析历史查询日期。地区词可能描述申请人的居住地而非办理地，复杂问题仍需人工确认。先前上下文的事项自动切换也未完成通用语义消歧；不要宣称已能理解所有自然语言表达。

## 实际验证

- 完整回归：107 passed、1 skipped，2 条已有上游弃用警告。新增用例覆盖原问句、候选确认、同名近似事项、跨省隔离、未发布/停用资料、候选超限、地区冲突及浏览器一键确认。
- `python -m scripts.validate_query_recall` 使用真实本地 HTTP、Neo4j、DeepSeek 和 Edge：原问句返回 1 个已发布候选；确认太平区事项后返回 6 条办理条件事实、6 条可定位引文；引用可打开原件。没有把离线模型替身视为真实推理。
- 实际 API 验证广东省问题返回无该地区已发布资料，未调用模型、未引用辽宁资料。
- 报告及候选/答案/原文截图保存在 `test-results/query-recall/`。指南文本含既有识别异常，检索修复不代表已重新校对真实原始 PDF，政策现行有效性仍按原有机制提示核实。
